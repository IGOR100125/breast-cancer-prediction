# breast-cancer-prediction
Proyek ini membangun model Machine Learning (Logistic Regression) untuk memprediksi tumor payudara ganas atau jinak menggunakan dataset Wisconsin. Tahapannya mencakup EDA, seleksi fitur (menghapus fitur redundan), dan standarisasi data. Evaluasi berfokus pada metrik Recall untuk meminimalisir kesalahan deteksi pada pasien kanker.
